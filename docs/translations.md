# Translations

The words of the CMIL commands in each language, from [`src/translations/languages`](../src/translations/languages). A command may have more than one word; any of them works, and `translate()` writes the first.

Do you speak one of these languages? If a word is wrong, unusual or hard for children, [suggest a better one](https://github.com/LinguaCode/cmil/issues/new?template=translation.yml), or change the language file yourself (see [CONTRIBUTING.md](../CONTRIBUTING.md#how-to-translate)). The words *to check* need a native speaker most.
