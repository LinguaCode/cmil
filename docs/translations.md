# Translations

Do you speak one of these languages? If a word is wrong, unusual or hard for children, [suggest a better one](https://github.com/LinguaCode/cmil/issues/new?template=translation.yml), or change the language file yourself (see [CONTRIBUTING.md](../CONTRIBUTING.md#how-to-translate)).
